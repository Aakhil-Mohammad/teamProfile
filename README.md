# Team Profile Card

A simple and responsive React application that displays team members in individual profile cards. Each card includes the member's photo, name, role, and department.

I built this project using React and CSS to practise creating reusable components and passing data through props.

## Preview

The application displays team members in a clean card layout with their profile pictures and professional details.

## Built With

- React
- JavaScript (JSX)
- CSS
- HTML

## Features

- Displays team members using profile cards.
- Shows each member's name, role, profile picture, and department.
- Uses reusable React components.
- Passes member details through props.
- Keeps the component structure simple and organised.

## Getting Started

To run this project on your computer:

**1. Clone the repository**
git clone YOUR_GITHUB_REPOSITORY_URL


**2. Open the project folder**
cd TeamProfileCard


**3. Install dependencies**
npm install


**4. Start the development server**
npm run dev

Open the local URL displayed in your terminal to view the application.
